# Changelog

## 0.1.0 — 2026-11-02

- Initial Claude Code plugin with local stdio MCP integration and configurable binary path.
- Commands for recording completed activities, listing projects, today's status, weekly reports and setup.
- Stable retry references, partial-error reporting and timezone-aware workflow instructions.
- Five real-binary integration tests and native Claude package validation.
- Public repository marketplace and a standalone plugin ZIP for transfer to another device.

Recording creates local manual activities for later aggregation. Timer control and direct time-entry writes are not available in the current MCP contract.
